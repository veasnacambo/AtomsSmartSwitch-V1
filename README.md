
# Atoms Smart Switch V1

Smart Switch Version 1 is the first prototype of the Atoms smart control product line.

## Project Goal

Build a reliable smart switch from basic prototype to commercial-ready product.

Version 1 focuses on:

- Relay ON/OFF control
- Manual push button control
- LED status indication
- Wi-Fi local control
- State memory after reboot

---

## Development Strategy

The project is developed in modular stages:

### Stage 1
- Relay control
- Button input
- LED status

### Stage 2
- Wi-Fi AP mode
- Local web control

### Stage 3
- Save relay state
- Basic protection logic

### Stage 4
- PCB design
- Product enclosure

### Stage 5
- Commercial product upgrade
